Prompt Library
Getting Started

Welcome to your personal prompt library. Load prompt packs using the "Load Pack" button in the sidebar, then browse, search, and copy prompts to use with any AI assistant.

Features
  • Load and manage multiple prompt packs (JSON format)
  • Search prompts by title, description, or content
  • Filter by category and tags
  • Fill in template variables before copying
  • Save favorites for quick access
  • Create custom collections to organize prompts
  • Export selected prompts as new packs
  • Dark and light themes
  • Keyboard shortcuts for power users (press ? to view)
Tips

Use Ctrl/Cmd+K to quickly focus the search bar. Press j/k or arrow keys to navigate between cards. Press Enter to expand a card, and c to copy the prompt.

Your favorites, collections, and loaded packs are saved in your browser's local storage.
